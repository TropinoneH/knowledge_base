##### asar快速压缩解压缩

###### 解压缩:

下载asar:

```shell
npm install asar -g
```

到*.asar所在文件夹下输入:

```shell
asar extract *.asar ./*
```

###### 压缩:

```shell
asar pack ./ app.asar
```

这是相当于将打开终端位置(父文件夹)全部打包成app.asar

##### IntelliJ激活(至少目前有用):

1. 进入`3.jetbra.in`中任意一个可以进入的网站
2. 下载`jetbra.zip`
3. 解压, 并放在一个特定位置
4. 手动hack
   - 编辑 `<jetbrains>/bin/<jetbrains>.vmoptions`文件
   - 写入:
```
--add-opens=java.base/jdk.internal.org.objectweb.asm=ALL-UNNAMED
--add-opens=java.base/jdk.internal.org.objectweb.asm.tree=ALL-UNNAMED
-javaagent:/usr/local/applications/jetbrains/jetbra/ja-netfilter.jar=jetbrains
```
5. 打开程序
6. 输入`3.jetbra.in`进入的网站中的对应的验证码

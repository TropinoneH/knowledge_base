# PyTorch3D安装问题

如果使用[[Conda]]安装[[Cuda]], 那么可能会导致[[Python Module#Install|安装]][PyTorch3D](https://github.com/facebookresearch/pytorch3d)的时候有各种各样的问题, 无法成功安装.

但是如果不使用conda的cuda, 还是可能会有无法安装的情况. 这种时候需要使用第三方的安装.

使用: [third-party](https://github.com/facebookresearch/pytorch3d/discussions/1752)

# Obsidian

## Normal usage

use [[markdown]] to write notes

most recent key shortcut is <kbd>Ctrl+P</kbd>, which means open the command panel.

another key shortcut is <kbd>Ctrl+O</kbd>, which means open the file panel. you can search or create new files in this panel.

<kbd>Ctrl+,</kbd> will open settings panel.

## Link

the most famous function of obsidian is the `Link`. use `[[]]` to create double-wise link.

you can link a note such as [[obsidian]], or you can link to a file such as [[./obsidian.md]].

well, the link to a note could add the subtitle, such as [[obsidian#Link]].

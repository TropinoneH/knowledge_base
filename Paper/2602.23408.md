# Motivation

研究动作空间如何影响模仿学习的效果

# Contribution

1. 使用Chunk-wise Delta Actions全面优于Absolute Actions, 但是Step-wise Delta Action比Absolute Action更差
2. 在数据充足、模型能力强(如[[2210.02747|Flow Matching]]或者[[Diffusion Transformer]]等模型)的情况下, 使用joint-space更优秀; 但是在cross-embodiment、transfer learning相关的场景下, 使用End-Effector space更佳
3. action horizon不应该是一个独立的超参数, Delta模式需要更短的执行窗口以避免轨迹漂移、absolute模式使用更长的horizon能够更好的保证一致性

总结:
1. 优先使用Chunk-wise delta actions
2. 做通用机器人的模型(做cross-embodiment), 推荐使用eef控制
3. 推荐训练时horizon=60, 使用chunk-wise delta action推理时使用horizon=15~30

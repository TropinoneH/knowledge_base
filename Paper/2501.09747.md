# Motivation

使用频域将连续的robot action sequence转换成更紧凑的表示.

# Methods

1. 归一化: 将action归一化到统一的标准范围
2. 离散余弦变换: 使用[[DCT]]处理每一个动作的维度, 将时间序列转换为频域分量
3. 量化: 将DCT系数量化成离散值(先经过一个缩放然后再round: $\bar C_{i,j}=\text{round}(\gamma\cdot C_{i,j})$, 这里面的缩放因子是超参数, 实验证明, 并不敏感)
4. 展平: 将系数矩阵展平成一维向量
5. [[Hands-On Large Model Engineering#Lecture 04|BPE]]编码: 使用BPE进一步压缩, 用以创建最终的序列
